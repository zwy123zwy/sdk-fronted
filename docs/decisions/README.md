## 状态说明

- **待确认**：已给出建议方案，确认人尚未签署。Agent 不得把建议方案当作结论使用。
- **已确认**：确认人已签署，内容冻结。修改需要新建一条决策记录，并在原记录中注明“已被 Dxxx 取代”。
- **已取代**：被后续记录取代，仅保留历史。
