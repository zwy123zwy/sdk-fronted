# T09 M01 本地 mock 接收服务

- 阶段 / 执行 Agent / 对接负责人*：P1 / A13 / 架构负责人
- 依赖任务及验收状态*：T05、T08（未验收）；D001、Q4 已确认
- 截止时间：2026-11-13（M2）

## 目标*
提供一个实现 `receiver-requirements.md` 全部“必须”条目的本地接收服务，带故障注入与计数接口，供 POC、单元集成、E2E 和可靠性对账使用。不得用于生产。

## 需求编号*
- M01-F1 实现上报协议 I-01 的请求校验与响应码（必须）
- M01-F2 按 `app_id` + `event_id` 去重并入库到内存或本地文件（必须）
- M01-F3 故障注入：按比例或按序列返回 429、5xx、413、401、超时、断连（必须）
- M01-F4 计数与查询接口：收到、去重后、拒绝，按原因码分类（必须）
- M01-F5 托管远程配置发布物，支持 `ETag` / 304（必须）
- M01-F6 一条命令启动，可被 Playwright 和 Vitest 以编程方式启停（必须）

- 只监听 `127.0.0.1`，默认端口由 T08 统一分配。

## 交接产物*
