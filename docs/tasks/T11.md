- 阶段 / 执行 Agent / 对接负责人*：P2 / A02 / 前端负责人

- C02-F2 六段处理管线（必须）

- C02-F4 插件宿主（必须）
- C02-F5 预启动队列（必须）
- C02-F6 全局注册表（必须）

- 行覆盖率不低于 90%，分支覆盖率不低于 80%。
