# T22 K01 事件注册表与类型生成 CLI

- 阶段 / 执行 Agent / 对接负责人*：P3 / A06 / 前端负责人、产品负责人
- 依赖任务及验收状态*：T06、T08（未验收）；Q3 已确认
- 截止时间：2026-12-04

## 目标*
接入方在自己仓库中用 `events/*.json` 维护事件定义；K01 在 CI 中做格式与兼容性检查，生成 TypeScript 类型（含投递等级），并导出可供接收方使用的校验规则。替代原 S03 字典服务。

## 需求编号*
- K01-F1 事件定义校验（`event-definition.schema.json`）（必须）
- K01-F2 兼容性检查：对比 git 基线版本，按 `dictionary-compat.md` 判定（必须）
- K01-F3 critical 配额检查：不超过注册表事件总数的 10%（Q3）（必须）
- K01-F4 生成类型声明，事件名携带投递等级（必须）
- K01-F5 导出运行期校验规则 JSON（应该）
- K01-F6 未登记事件报告：读取 M01 或接收方导出的事件名清单，列出注册表中没有的事件（应该）
