# T03 POC-2 网关吞吐

- 阶段 / 执行 Agent / 对接负责人*：P0 / A05 / 服务端负责人（结对）
- 依赖任务及验收状态*：无（D001 确认为“整套平台”时才执行）
- 截止时间：2026-10-30

## 目标*
用至少两种候选语言实现最小网关（鉴权、限流、解压、快速校验、写入消息队列后返回 202），测出单实例吞吐和延迟，作为 Q4 网关语言选型的依据。

S01-F1 至 S01-F4、S01-F6（验证可行性，不要求完整实现）。

## 验收用例*
POC 报告使用 `docs/templates/poc-report.md`，必须包含：
- 每个候选在相同规格（写明 CPU、内存）下的单实例批次请求/秒、P50/P99 延迟、内存占用；
- 请求体分别为 1 KB、8 KB、60 KB，gzip 与不压缩各一组；
- 消息队列写入确认开启时的数据（必须是“写入成功后才返回 202”）；
- 与目标（单实例不少于 1,500 请求/秒，P99 不超过 50 ms）对比的结论和推荐。
