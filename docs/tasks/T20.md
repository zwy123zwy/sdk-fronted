# T20 客户端性能基准与体积报告

- 阶段 / 执行 Agent / 对接负责人*：P2 / A10 / 质量负责人
- 依赖任务及验收状态*：T12–T18（未验收）
- 截止时间：2026-12-18（M3，关键路径）

## 目标*
在基准设备上测量客户端全部性能和体积指标，建立后续版本比较的基线，并接入 CI：劣化超过 10% 时阻断合入。

## 需求编号*
C01–C08 的“⑥ 性能指标”；总体方案“性能指标汇总”中的客户端行。

## 契约引用*
无。

## 上下文切片*
- 总体方案：性能指标汇总、性能测试
- 各客户端模块的性能指标小节

## 文件所有权*
- 可写：`tests/bench/`、`docs/reports/client-bench-*.md`
- 只读参考：`packages/`
- 禁止修改：实现代码

## 验收用例*
报告包含以下每一项的测量方法、原始数据和是否达标：
- `track` 同步耗时、管线耗时、入队、批次组装与序列化、采样判定、富化与脱敏；
- 加载桩、核心包、插件全量的 gzip 体积；
- 常驻内存；
- 采集过程中的长任务数量；
- 基准设备：4 核 CPU、Chrome 最新稳定版、限速 4 倍 CPU。

## 非功能目标
基准测试可以在 CI 中复现，结果波动在 5% 以内（给出多次运行的方差）。

## 交接产物*
基线数据文件；CI 中的基准比较任务。

## 禁止事项与升级条件
任一指标不达标时，在报告中列出并升级给前端负责人，不得调整测量方法来“达标”。
