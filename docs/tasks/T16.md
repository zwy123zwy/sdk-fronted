## 非功能目标
- 离线读写全部异步；单次写入阻塞主线程不超过 1 ms。
- 补发不超过每秒 2 个批次；健康期重试流量占比不超过 5%。
- 发送请求必须使用 hook 前保存的原生 `fetch` / `XMLHttpRequest` 引用，不被 C05 的 HTTP 插件采集。
- 行覆盖率不低于 90%。

## 交接产物*
发送器、离线存储、选主模块；在途状态与熔断信号接口（给 T15）；投递计数（给 T17）；清理离线数据接口（给 T14）。

## 禁止事项与升级条件
- 高风险任务：计划需前端负责人确认后再动手。
- 丢失率达不到 POC-1 的结论时立即升级（风险 R02）；进度风险触发时可以按 R06 预案把多标签页选主降级为接收方去重兜底（`receiver-requirements.md` RR-05），但需要前端负责人书面批准。
- 离线数据只保存已脱敏的内容，格式带版本号；格式不兼容时清理，不报错。
