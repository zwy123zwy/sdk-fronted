# T25 K02 配置签名 CLI

- 阶段 / 执行 Agent / 对接负责人*：P3 / A08 / 前端负责人、安全负责人
- 依赖任务及验收状态*：T07、T08（未验收）
- 截止时间：2026-12-11

## 目标*
接入方用 K02 校验配置正文、生成签名发布物，自行托管到静态资源服务。替代原 S02 配置中心。

## 需求编号*
- K02-F1 按 `remote-config.schema.json` 校验正文（必须）
- K02-F2 检查 `config_version` 单调递增（对比上一份发布物）（必须）
- K02-F3 ES256 签名，输出 `remote-config.md` 第 4 节格式的发布物（必须）
- K02-F4 验签子命令，用于发布前自检（必须）
- K02-F5 生成测试密钥对（只用于测试）（必须）
- K02-F6 签名私钥来源可替换：本地文件（测试）或外部签名命令（接入方的 KMS）（应该）
