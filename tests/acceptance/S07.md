# S07 管理控制台：验收用例

对应任务：T27。

| 用例 | 需求 | 前置 / 操作 | 预期结果 |
|---|---|---|---|
| S07-AC-01 | S07-F1 | 创建应用 | 生成 `app_id` 与只写令牌；令牌只完整展示一次，之后掩码显示；数据库只存哈希 |
| S07-AC-02 | S07-F1 | 轮换令牌 | 新令牌生效；旧令牌在设定的过渡期后失效，网关 60 秒内同步 |
| S07-AC-03 | S07-F1 | 配置来源域名白名单与配额 | 网关同步后生效 |
| S07-AC-04 | S07-F2 | 编辑配置与字典，查看差异，提交审批，发布，回滚 | 全流程可用，调用 S02、S03 的管理接口 |
| S07-AC-05 | S07-F3 | 四种角色分别执行管理操作 | 权限与角色定义一致；越权操作被拒绝 |
| S07-AC-06 | S07-F4 | 按人、时间、对象查询审计 | 所有管理操作都能查到 |
| S07-AC-07 | S07-F5 | 用接入向导创建初始化参数，运行自检 | 自检能检测到首批数据到达 |
| S07-AC-08 | S07-F6 | 提交、审批、跟踪个人信息删除请求 | 状态可跟踪；完成后有删除记录 |
| S07-AC-09 | S07 安全 | 会话 30 分钟无操作 | 会话过期 |
| S07-AC-10 | S07 安全 | 高风险操作（吊销令牌、开启 kill switch、导出） | 需要二次确认与双人审批 |
