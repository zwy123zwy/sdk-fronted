# S04 数据处理管道：验收用例

> **已废弃（D001，2026-10-10）**：服务端不在本项目范围，无替代；接收方的去重与校验要求见 `docs/contracts/receiver-requirements.md`。只保留历史，不再作为验收依据；用例编号不复用。

对应任务：T23。原因码见 `docs/contracts/reason-codes.md` 第 3 节。

| 用例 | 需求 | 前置 / 操作 | 预期结果 |
|---|---|---|---|
| S04-AC-01 | S04-F1 | 消费 `batch.valid.json` 与 `batch-promoted.valid.json` | 拆成单条事件入库；`common` 中的字段正确还原到每条事件 |
| S04-AC-02 | S04-F1 | 必填字段缺失、类型不符、枚举值不在列表中 | 分别进入死信，原因码为 `schema_missing_required`、`schema_type_mismatch`、`schema_enum_mismatch` |
| S04-AC-03 | S04-F1 | 未登记事件 | 打 `unregistered` 标签后入库，并回传给 S03 |
| S04-AC-04 | S04-F1 | 事件含定义之外的字段 | 丢弃该字段，计数 `unknown_field`，事件入库 |
| S04-AC-05 | S04-F1 | 事件的 `schema_version` 已 retired；另测 deprecated | 前者进死信 `schema_retired`；后者入库并计数 |
| S04-AC-06 | S04-F2 | 同一 `event_id` 在 1 小时内、6 天后各到达一次 | 都只入库一次，计数 `duplicate` |
| S04-AC-07 | S04-F2 | 去重缓存不可用 | 不丢数据；由明细库去重兜底，最终重复率不超过 0.01% |
| S04-AC-08 | S04-F3 | 检查富化结果 | IP 转地域到市级；UA 已解析；`clock_offset` 已修正时间；采样权重等于 1 / `sample_rate` |
| S04-AC-09 | S04-F4 | 字典中标记为 mask、hash、drop 的字段 | 分别被掩码、哈希、删除 |
| S04-AC-10 | S04-F4 | 端上漏掉的手机号出现在 `message` 维度 | 被二次脱敏 |
| S04-AC-11 | S04-F5 | 配置一条订阅规则 | 命中的事件转发到业务订阅主题；原始批次写入归档 |
| S04-AC-12 | S04-F6 | 修复 Schema 后重放一天的死信 | 事件入库，重放不产生重复；重放操作有审批与审计记录 |
| S04-AC-13 | S04 处理幂等 | 同一条队列消息被消费两次 | 入库结果与消费一次相同 |
| S04-AC-14 | S04 安全 | 检查死信、归档、日志 | 都不含未脱敏的个人信息和完整 IP |
