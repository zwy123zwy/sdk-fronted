# C04 上下文与隐私守卫：验收用例

对应任务：T14。同意相关用例以 Q5 与 D002 的确认结论为准；结论变化时由 A09 修订。

| 用例 | 需求 | 前置 / 操作 | 预期结果 |
|---|---|---|---|
| C04-AC-01 | C04-F1 | 上报一条事件 | 批次头包含 `device_id`、`session_id`、`release`、`env`、`sdk_version`；事件包含 `page_id`、`view_id`、`url` |
| C04-AC-02 | C04-F1 | 模拟 31 分钟无活动后再上报 | `session_id` 变化；29 分钟时不变 |
| C04-AC-03 | C04-F2 | 在页面 A 上报后立即切换路由到 B，再发送批次 | 该事件的 `page_id`、`view_id` 仍为 A 的值；B 的事件使用新的 `view_id` |
| C04-AC-04 | C04-F2 | 路由 `/task/123` | `page_id` 为路由模板 `/task/:id` |
| C04-AC-05 | C04-F3 | 设置自定义上下文 `k1`，上报，删除 `k1`，上报 | 第一条事件 `context.k1` 存在，第二条不存在 |
| C04-AC-06 | C04-F4 | URL 带查询参数 `tab`、`token`、`phone`，白名单只有 `tab` | 上报的 `url` 只保留 `tab` |
| C04-AC-07 | C04-F4 | 错误信息与维度中包含伪造的手机号、邮箱、身份证号 | 全部被掩码；计数不影响事件上报 |
| C04-AC-08 | C04-F4 | 远程配置追加一条规则 `ORD\d{12}` | 匹配内容被替换为配置的 `replacement` |
| C04-AC-09 | C04-F4、C04 安全 | 远程配置或运行时覆盖试图关闭内置脱敏规则 | 内置规则仍然生效 |
| C04-AC-10 | C04-F5 | 同意状态 `unknown`，`consent_mode` 为 `essential_only` | 只发送必要事件，其他事件计数 `consent_denied`；不写入持久化设备标识；批次 `device_id_persistent` 为 false |
| C04-AC-11 | C04-F5 | `consent_mode` 为 `buffer`，先上报 10 条，再设置 `granted` | 10 条事件在同意后发送；同意前没有网络请求 |
| C04-AC-12 | C04-F5 | 设置 `denied` | 清除设备标识、离线数据、会话随机数；之后只发送必要事件，其他事件计数 `consent_denied` |
| C04-AC-13 | C04-F6 | 维度值 300 字符、60 个维度键、10 KB 附件 | 截断到 256 字符、50 个键、8 KB；`truncated` 列出路径；计数对应原因码 |
| C04-AC-14 | C04-F6 | 截断位置落在表情符号（代理对）中间 | 不产生孤立代理项 |
| C04-AC-15 | C04-F6 | 单条事件截断后仍超过 16 KB | 整条丢弃，计数 `event_too_large` |
| C04-AC-16 | C04-F7 | 接收方响应头 `X-Server-Time` 比本地快 5 秒，往返 100 ms；另测往返 3 秒 | 前者 `clock_offset` 约为 5000 且 `clock_calibrated: true`；后者放弃校准 |
| C04-AC-17 | C04-F6 | 维度键 `Title`、`1abc`；60 个指标键 | 两个非法键被丢弃并计数 `invalid_field_key`；指标保留 50 个并计数 `truncated_metric_keys` |
| C04-AC-18 | C04-F5 | `consent_mode` 为 `buffer`，先上报 10 条，再设置 `denied` | 缓存的 10 条被清空，计数 `consent_buffer_cleared` 为 10；全程没有业务事件的网络请求 |
| C04-AC-19 | C04-F5、D002 | 初始化参数 `consent_mode: full`，同意状态 `unknown` | 全部事件采集并发送；生成持久化设备标识；批次 `consent` 为 `unknown` |
| C04-AC-20 | C04-F4 | 检查内置敏感请求头与内置脱敏规则 | 与 `remote-config.md` 5.4 的清单逐项一致 |
