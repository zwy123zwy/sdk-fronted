# S01 接入网关：验收用例

> **已废弃（D001，2026-10-10）**：服务端不在本项目范围。本文件由 `M01.md` 与 `docs/contracts/receiver-requirements.md` 取代，只保留历史，不再作为验收依据；用例编号不复用。

对应任务：T21。协议细节见 `docs/contracts/ingest-protocol.md`，样例见 `docs/contracts/examples/`。

| 用例 | 需求 | 前置 / 操作 | 预期结果 |
|---|---|---|---|
| S01-AC-01 | S01-F1 | 发送 `batch.valid.json`，令牌正确 | 202；消息队列中出现一条消息 |
| S01-AC-02 | S01-F1 | 令牌错误；令牌已吊销 | 401，`error` 为 `invalid_token` / `token_revoked`；吊销后 60 秒内生效 |
| S01-AC-03 | S01-F1 | `Origin` 不在白名单 | 403，`origin_not_allowed` |
| S01-AC-04 | S01-F1 | 请求头 `X-App-Id` 与请求体 `app_id` 不一致 | 400，`app_id_mismatch` |
| S01-AC-05 | S01-F2 | 单个应用超过限流阈值 | 429，带整数 `Retry-After`；其他应用的请求不受影响 |
| S01-AC-06 | S01-F2 | 单个 IP 超过限流阈值 | 429 |
| S01-AC-07 | S01-F3 | 发送 `batch.invalid.json` 中的每个 case | 都返回 400 |
| S01-AC-08 | S01-F3 | 解压后 1.2 MB；501 条事件 | 413，`payload_too_large` / `too_many_events` |
| S01-AC-09 | S01-F3 | 发送 gzip 炸弹（压缩后 100 KB，解压后 1 GB） | 解压到 1 MB 即中止，返回 413；网关内存不出现明显增长 |
| S01-AC-10 | S01-F4 | 消息队列不可用 | 返回 503，`queue_unavailable`；绝不返回 2xx |
| S01-AC-11 | S01-F4 | 消息队列写入超时 | 返回 503；客户端重试后服务端只入库一次（与 S04 联合验证） |
| S01-AC-12 | S01-F5 | 检查写入队列的消息 | 含 `received_at`、截断后的 IP、`gateway_instance`、`channel`；不含完整 IP |
| S01-AC-13 | S01-F6 | 发送 gzip 请求；发送信标通道请求 | 都返回 202；信标请求的 `auth` 字段不出现在队列消息中 |
| S01-AC-14 | S01-F6 | 常规通道请求体中带伪造的 `auth` 字段，请求头令牌错误 | 401（只认请求头） |
| S01-AC-15 | S01 安全 | 检查全部日志 | 不出现令牌、完整 IP |
