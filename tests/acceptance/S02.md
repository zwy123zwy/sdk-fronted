# S02 配置中心：验收用例

对应任务：T25。

| 用例 | 需求 | 前置 / 操作 | 预期结果 |
|---|---|---|---|
| S02-AC-01 | S02-F1 | 为一个应用的两个环境分别保存配置 | 正文通过 `remote-config.schema.json` 校验；不合法的配置无法保存 |
| S02-AC-02 | S02-F2 | 连续发布 3 次 | 生成 3 个不可变版本，`config_version` 单调递增 |
| S02-AC-03 | S02-F2 | 回滚到第 1 个版本 | 生成新版本（内容等于版本 1，`config_version` 更大），SDK 能接受 |
| S02-AC-04 | S02-F3 | 配置 `session_bucket` [0, 5] 的灰度 | 发布物包含 `overrides`；约 5% 的模拟会话命中 |
| S02-AC-05 | S02-F4 | 把采样率从 1 降到 0.4；另测开启 kill switch | 都需要两名不同的审批人；同一人无法自审 |
| S02-AC-06 | S02-F5 | 发布 | 发布物带签名，用测试公钥验签通过；CDN 缓存被刷新 |
| S02-AC-07 | S02-F5 | 测量发布到 CDN 可读取的时间 | 不超过 2 分钟 |
| S02-AC-08 | S02 安全 | 在配置中填入疑似令牌或密钥的字符串 | 保存被拒绝 |
| S02-AC-09 | S02 安全 | 发布、回滚、审批 | 都写入审计日志，可追溯到具名操作人 |
