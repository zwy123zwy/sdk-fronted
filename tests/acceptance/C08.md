# C08 自监控与调试：验收用例

对应任务：T17。字段定义见 `docs/contracts/reason-codes.md` 第 4 节。

| 用例 | 需求 | 前置 / 操作 | 预期结果 |
|---|---|---|---|
| C08-AC-01 | C08-F1 | 依次触发 `reason-codes.md` 第 1 节的每一种丢弃 | 每个原因码的计数都正确 |
| C08-AC-02 | C08-F1 | 正常上报 100 条并发送成功 | `calls_total`、`events_enqueued`、`events_sent` 与实际一致 |
| C08-AC-03 | C08-F2 | 会话命中 1% 耗时采样；另测未命中 | 命中时 `sdk_health` 带 `track_p99_ms` 等字段；未命中时不带 |
| C08-AC-04 | C08-F3 | 运行 60 秒 | 上报一条 `sdk_health`，`window_ms` 约为 60000；值为 0 的计数不出现 |
| C08-AC-05 | C08-F3 | `sdk_health` 本身被发送、重试 | 不计入下一个窗口的计数 |
| C08-AC-06 | C08-F3 | 一个窗口内非零指标超过 50 个 | 拆成多条 `sdk_health`，每条不超过 50 个指标 |
| C08-AC-07 | C08-F3 | 1,000 条业务事件期间的自监控流量 | 自监控事件体积不超过业务事件体积的 1% |
| C08-AC-08 | C08-F4 | 非生产环境通过 URL 参数开启调试模式 | 控制台逐条显示事件去向与原因码；不显示令牌 |
| C08-AC-09 | C08-F4 | 生产环境、非白名单用户使用同样的 URL 参数 | 调试模式不开启 |
