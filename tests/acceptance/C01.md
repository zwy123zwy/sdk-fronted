# C01 公共 API 与加载器：验收用例

对应任务：T12。API 名称以 `docs/use-cases.md` 定稿后的为准；下文用 `track`、`log`、`setContext`、`removeContext`、`setUser`、`flush`、`setConsent`、`destroy` 指代。

| 用例 | 需求 | 前置 / 操作 | 预期结果 |
|---|---|---|---|
| C01-AC-01 | C01-F1 | 依次调用全部公共方法，参数合法 | 每个方法同步返回 `undefined`；对应能力生效 |
| C01-AC-02 | C01-F1 | 让内部任意一个处理器抛错后再调用 `track` | `track` 不抛错；计数 `processor_error` 加 1 |
| C01-AC-03 | C01-F1 | 销毁后调用全部公共方法 | 不抛错；计数 `destroyed` |
| C01-AC-04 | C01-F2 | SDK 未初始化时调用 `track` 3 次、`setUser` 1 次，然后初始化并启动 | 按调用顺序回放；事件的 `occurred_at`、`page_id`、`url` 为调用当时的值 |
| C01-AC-05 | C01-F2 | 未就绪时调用 250 次 | 只保留前 200 次；计数 `command_queue_overflow` 为 50 |
| C01-AC-06 | C01-F3 | 页面头部内联加载桩，主包延迟 3 秒加载，期间抛出一个 JS 错误并调用 `track` | 主包加载后两者都被上报 |
| C01-AC-07 | C01-F3 | 主包加载失败（404） | 加载桩不抛错，不影响页面；命令队列不超过上限 |
| C01-AC-08 | C01-F3 | 构建产物检查 | 加载桩 gzip 后不超过 1 KB |
| C01-AC-09 | C01-F4 | 用测试类型包，以未登记事件名、缺失必填字段、错误字段类型调用 `track` | `tsc` 报错；以正确参数调用时编译通过 |
| C01-AC-10 | C01-F5 | 同一页面创建两个使用不同 `app_id` 的实例 | 上下文、队列、配置互相隔离；全局注册表只注册一次原生监听 |
| C01-AC-11 | C01-F6 | 用非法事件名、非对象维度、`NaN` 指标调用 `track` | 静默丢弃或丢弃该字段；计数 `invalid_event_name`、`invalid_args`、`non_finite_metric` |
| C01-AC-12 | C01-F6 | 开启调试模式后重复 AC-11 | 控制台输出警告，内容包含原因码，不包含令牌 |
