# K02 配置签名 CLI：验收用例

对应任务：T25。格式见 `docs/contracts/remote-config.md`，正文 Schema 见 `schemas/remote-config.schema.json`。部分用例改编自已废弃的 `S02.md`。测试密钥在测试运行时生成，不提交到仓库。

| 用例 | 需求 | 前置 / 操作 | 预期结果 |
|---|---|---|---|
| K02-AC-01 | K02-F1 | 校验 `remote-config.valid.json` 的 `decoded_payload`；逐个校验 `remote-config.invalid.json` 的 case | 前者退出码 0；后者每个都非零退出码，错误信息含字段路径；含 `consent_mode: full` 的 case 提示 D002 |
| K02-AC-02 | K02-F2 | 上一份发布物 `config_version` 为 42，新正文分别为 42、41、43 | 42、41 非零退出码；43 通过 |
| K02-AC-03 | K02-F3 | 用测试私钥签名 | 输出符合 `$defs/envelope`；`signature` 为 86 字符 base64url；用 WebCrypto（Playwright Chromium）验签通过 |
| K02-AC-04 | K02-F3、K02-F4 | 签名后篡改 `payload` 任意一个字节；另测篡改 `signature`、改 `key_id` | `verify` 子命令都返回非零退出码 |
| K02-AC-05 | K02-F5 | 生成测试密钥对 | 输出私钥 PEM 文件（权限 0600）与公钥 JWK；终端输出与日志中不含私钥内容 |
| K02-AC-06 | K02-F6 | 使用外部签名命令（测试中用一个调用 Node `crypto` 的脚本代替 KMS） | 产出的发布物与 AC-03 一样能验签通过；K02 进程不接触私钥 |
| K02-AC-07 | K02 安全 | 正文任意字符串字段中填入疑似令牌或密钥（JWT、PEM 头、32 位以上随机十六进制串） | 非零退出码，指出字段路径；不打印该字符串原文 |
| K02-AC-08 | K02 安全 | 运行全部用例后扫描仓库和 K02 的标准输出、错误输出 | 未出现私钥内容；仓库中没有新增私钥文件 |
| K02-AC-09 | K02 非功能 | 签名与验签各执行 100 次 | 单次不超过 100 ms |
