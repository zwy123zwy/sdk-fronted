# C05 采集插件与双写适配器：验收用例

对应任务：T18（AC-01 至 AC-14、AC-19、AC-20）、T19（AC-15 至 AC-18）。内置事件结构以 `docs/contracts/schemas/builtin-events/` 为准。

| 用例 | 需求 | 前置 / 操作 | 预期结果 |
|---|---|---|---|
| C05-AC-01 | C05-F1 | 页面抛出未捕获异常 | 上报 `web_js_error`，`source` 为 `window_error`，附带脱敏后的错误栈 |
| C05-AC-02 | C05-F1 | 未处理的 Promise 拒绝，拒绝值分别为 Error 对象和字符串 | 都上报，`source` 为 `unhandled_rejection` |
| C05-AC-03 | C05-F1 | 同一错误 1 秒内抛出 100 次 | 按 `fingerprint` 去重，上报次数受控，`count` 记录总次数；计数 `filtered_by_plugin` |
| C05-AC-04 | C05-F1 | 错误前用户做了 25 次点击和路由跳转 | 附带最近 20 条面包屑；面包屑中没有输入框内容 |
| C05-AC-05 | C05-F2 | 正常加载页面 | 上报 FCP、LCP、TTFB；交互后上报 INP；页面隐藏时上报 CLS |
| C05-AC-06 | C05-F2 | 页面上制造一个 120 ms 的长任务 | 上报 `web_long_task`，`duration_ms` 约为 120 |
| C05-AC-07 | C05-F2 | 浏览器不支持某个性能条目类型 | 不抛错，跳过该指标 |
| C05-AC-08 | C05-F3 | History 模式下 `pushState`、`replaceState`、后退 | 每次路由变化上报 `web_pageview`，`page_id` 为路由模板 |
| C05-AC-09 | C05-F3 | Hash 模式；另测手动模式 | Hash 变化上报；手动模式只在业务调用时上报 |
| C05-AC-10 | C05-F4 | 发出成功、404、超时三个请求（fetch 与 XHR 各一组） | 上报 `web_http`，状态码与失败原因正确；SDK 自己的上报请求不被采集 |
| C05-AC-11 | C05-F4、C05 安全 | 请求带 `Authorization` 头和含令牌的查询参数 | 上报中不出现这两项 |
| C05-AC-12 | C05-F4 | 配置追踪白名单只含同源，分别请求同源与第三方 | 只有同源请求被注入链路追踪头 |
| C05-AC-13 | C05-F6 | 只引入错误插件构建 | 产物中不包含其他插件代码 |
| C05-AC-14 | C05-F6 | 远程配置关闭性能插件 | 性能观察器断开，之后不再上报性能事件 |
| C05-AC-15 | C05-F5 | 注入一个模拟的第三方 APM 接口，开启双写 | 每条自定义事件按映射配置转发一次 |
| C05-AC-16 | C05-F5 | 第三方接口抛错或不存在 | 本 SDK 正常上报；计数 `processor_error` |
| C05-AC-17 | C05-F5 | 关闭双写 | 不再转发 |
| C05-AC-18 | C05-F5 | 适配器构建产物检查 | 不包含任何第三方包的代码；gzip 后不超过 1.5 KB |
| C05-AC-19 | Q7 共存 | 第三方 APM 先于本 SDK 初始化，两边都 hook `fetch` 与 `onerror`；然后反过来再测一次 | 两边都采集到数据；本 SDK 销毁后，第三方的 hook 仍然生效 |
| C05-AC-20 | Q7 共存 | 共存模式下的默认配置 | 错误、性能、HTTP 插件默认关闭；可通过远程配置逐个开启 |
