# C03 配置与采样：验收用例

对应任务：T13。配置样例见 `docs/contracts/examples/remote-config.valid.json`。

| 用例 | 需求 | 前置 / 操作 | 预期结果 |
|---|---|---|---|
| C03-AC-01 | C03-F1 | 内置默认、远程配置、运行时覆盖都设置了 `transport.max_batch_events` | 生效值取运行时覆盖；生效配置带远程配置的 `config_version` |
| C03-AC-02 | C03-F1 | 运行时覆盖试图开启远程已关闭的插件、修改采样率 | 被忽略；生效配置保持远程值 |
| C03-AC-03 | C03-F2 | 首次启动，配置接口返回 200 | 初始化不等待拉取；拉取完成后生效 |
| C03-AC-04 | C03-F2 | 第二次拉取带 `If-None-Match`，接口返回 304 | 不重新解析；继续使用缓存 |
| C03-AC-05 | C03-F2 | 接口返回 500，有未过期缓存 | 使用缓存；计数 `config_fetch_failed` |
| C03-AC-06 | C03-F2 | 接口失败且无缓存 | 使用保守默认：只保留 critical 与 JS 错误，其他插件关闭 |
| C03-AC-07 | C03-F2、C03 安全 | 发布物签名被篡改一个字节 | 拒绝本次配置；计数 `config_signature_invalid` |
| C03-AC-08 | C03-F2 | 收到的 `config_version` 小于当前生效版本 | 拒绝（防回放），保持当前配置 |
| C03-AC-09 | C03-F2 | `format_version` 为 2 | 使用缓存或保守默认；计数 `config_format_unsupported` |
| C03-AC-10 | C03-F3 | `session_rate` 0.3，同一会话内刷新页面 10 次 | 每次命中结果相同 |
| C03-AC-11 | C03-F3 | 10,000 个模拟会话，`session_rate` 0.3 | 命中比例在 0.28–0.32 之间 |
| C03-AC-12 | C03-F3 | 白名单用户所在会话的随机数未命中 | 仍全量采集 |
| C03-AC-13 | C03-F4 | 规则 `editor_*` 采样 0.1、`legacy_click_track` 采样 0；critical 事件命中 0 规则 | 前缀匹配生效，未命中 0.1 的事件计数 `sampled_out_rule`；禁用事件计数 `disabled_by_rule`；critical 事件仍上报；事件 `sample_rate` 等于会话率乘规则率 |
| C03-AC-14 | C03-F5 | 下发 `kill_switch.sdk_versions` 命中当前版本；另测 `plugins: ["http"]` | 前者进入已销毁状态，之后的事件计数 `killed`；后者只卸载 HTTP 插件并恢复其 hook |
| C03-AC-15 | C03-F6 | 会话未命中采样 | 错误、性能、路由、HTTP 插件的监听被拆除；critical 事件仍可上报；normal 事件计数 `sampled_out_session` |
| C03-AC-16 | C03-F2、C03 安全 | 发布物 `key_id` 不在 `config_public_keys` 中 | 拒绝本次配置；计数 `config_signature_invalid` |
| C03-AC-17 | C03-F2 | 正文 `app_id` 或 `env` 与请求路径不一致（签名正确） | 拒绝本次配置；计数 `config_scope_mismatch` |
| C03-AC-18 | C03-F2 | 响应体不是合法 JSON；另测 `payload` 不是合法 JSON（签名正确） | 都拒绝；计数 `config_parse_failed`；不抛错 |
| C03-AC-19 | C03-F2 | 本地缓存写入时间为 25 小时前，拉取失败 | 不使用该缓存，使用保守默认；计数 `config_cache_expired` 与 `config_fetch_failed` |
| C03-AC-20 | C03-F2 | 删除 `crypto.subtle` 后初始化 | 不发起验签；生效配置等于保守默认；计数 `config_signature_unavailable` |
| C03-AC-21 | C03-F1、D002 | 初始化参数 `consent_mode: buffer`，远程配置（签名正确）带 `consent_mode: full` | 生效值为 `buffer`；计数 `config_consent_mode_rejected`；配置的其他字段照常生效 |
| C03-AC-22 | C03-F1、D002 | 初始化参数 `consent_mode: full`，远程配置带 `essential_only` | 生效值为 `essential_only` |
| C03-AC-23 | C03-F2 | 未传 `config_endpoint` | 不发起配置请求；使用内置默认值 |
| C03-AC-24 | C03-F2 | 发布物/正文是**合法 JSON 但不符合 `remote-config.schema.json`**（另测：`sdk_versions` 用了 `remote-config.md` 5.1 节未列出的语法，如 `1.2.3 - 2.0.0`）（2026-10-13 经 CR-003 新增；同日修正措辞，见下） | **整份配置被拒绝**并计数 `config_schema_invalid`；**不得静默忽略该字段后继续使用其余配置**（否则一条无法求值的 kill switch 规则会被当作不命中）。被拒之后的生效配置按 `remote-config.md` 失败表的既有模式：**已有当前生效配置时保持该配置不变**；**没有可用配置时才退回保守默认**。—— 原先写作"退回保守默认"，与失败表其它拒绝行的语义不一致，且会造成**降级面**：推送一份非法配置即可把 SDK 打回最保守模式、停掉上报（对数据管道构成拒绝服务）。 |
