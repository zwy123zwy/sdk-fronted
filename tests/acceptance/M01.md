# M01 本地 mock 接收服务：验收用例

对应任务：T09。协议见 `docs/contracts/ingest-protocol.md`，要求见 `receiver-requirements.md`（RR 编号）。部分用例改编自已废弃的 `S01.md`。M01 只监听 `127.0.0.1`，令牌为固定占位值。

| 用例 | 需求 | 前置 / 操作 | 预期结果 |
|---|---|---|---|
| M01-AC-01 | M01-F1、RR-01 | 常规通道发送 `batch.valid.json`、`batch-promoted.valid.json`，令牌正确 | 都返回 202；响应带 `X-Server-Time`、`X-Request-Id` |
| M01-AC-02 | M01-F1、RR-01、RR-12 | 令牌错误；调用吊销接口后再用原令牌 | 401，`error` 分别为 `invalid_token`、`token_revoked` |
| M01-AC-03 | M01-F1、RR-03 | 信标通道（`text/plain`，令牌在 `auth`）；另测常规通道请求体带正确 `auth`、请求头令牌错误 | 前者 202；后者 401（只认请求头） |
| M01-AC-04 | M01-F1、RR-01、RR-04 | `batch.invalid.json` 每个 case；请求头 `X-App-Id` 与请求体不一致；`Content-Encoding: br`；解压后 1.2 MB；501 条事件；压缩后 100 KB、解压后 1 GB 的 gzip 炸弹 | 前三类 400（`invalid_structure`、`app_id_mismatch`、`unsupported_encoding`）；后三类 413，炸弹在解压到 1 MB 时中止，进程 RSS 增长不超过 50 MB |
| M01-AC-05 | M01-F3、RR-02 | 开启“存储失败”故障注入后发送批次 | 返回 503（`storage_unavailable`），从不返回 2xx；计数接口中入库数不变 |
| M01-AC-06 | M01-F2、RR-05、RR-23 | 同一批次重发 3 次；拆分后的两个批次含相同 `event_id`；批次含一条 `sdk_health` | 每个 `event_id` 只入库一次；计数接口 `received` 与 `stored` 的差等于重复数；`sdk_health` 入库 |
| M01-AC-07 | M01-F2、RR-06 | 发送 `batch-promoted.valid.json` | 查询接口返回的每条事件与未提升写法完全一致；事件体中的值优先于 `common` |
| M01-AC-08 | M01-F1、RR-08 | 发送 CORS 预检请求 | 允许 `POST` 与 RR-08 列出的请求头；`Access-Control-Expose-Headers` 含 `Retry-After`、`X-Server-Time` |
| M01-AC-09 | M01-F3 | 按序列注入 `[429, 503, 413, 401, timeout, reset, 202]`；另测按比例注入 30% 的 503 | 响应依次与序列一致，429 与 503 带整数 `Retry-After`；比例注入 1,000 次的 503 占比在 25%–35% |
| M01-AC-10 | M01-F4 | 发送合法、重复、被拒绝的批次各若干后查询计数接口 | 按 `received`、`stored`、`duplicate`、`rejected_<error>` 分类，数值与发送情况一致；提供清零接口 |
| M01-AC-11 | RR-13 | 运行 AC-01 至 AC-04 后检查 M01 的全部日志输出和入库数据 | 不出现令牌占位值、`auth` 字段和请求方 IP 的末段 |
| M01-AC-12 | M01-F5 | 托管一份 K02 生成的发布物，先后两次 GET，第二次带 `If-None-Match` | 第一次 200 带 `ETag`；第二次 304；替换发布物后再次请求返回 200 和新 `ETag` |
| M01-AC-13 | M01-F6 | 在 Vitest 中以编程方式启动、发请求、停止，重复 3 次 | 每次启动不超过 2 秒；停止后端口释放；未指定端口时自动分配空闲端口 |
| M01-AC-14 | M01 非功能 | 本地压测 30 秒，每批 15 条事件 | 每秒处理不少于 500 个批次，无错误响应 |
| M01-AC-15 | M01 安全 | 尝试监听 `0.0.0.0` | 启动失败并返回非零退出码；README 中有“不得用于生产”的说明 |
